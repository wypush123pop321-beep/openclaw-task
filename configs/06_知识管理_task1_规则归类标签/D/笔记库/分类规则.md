# 分类规则

> 用于给《待归类笔记.md》中的笔记重新归类、更新标签。
> 规则按优先级从高到低排列,哪条先命中就按哪条算,命中后不再往下匹配(首条命中即止)。
> 命中判定:标题或内容里出现规则列出的任一关键词即视为命中。

1. 标题或内容里出现 XSS、CSRF、漏洞、身份验证、HTTPS、安全 任一个 → 归「安全与合规」,标签 安全、技术
2. 出现 SQL、索引、缓存、延迟、P99、Redis 任一个 → 归「性能优化」,标签 性能、技术
3. 出现 用户研究、访谈、需求、注册流程、用户体验、UI、UX 任一个 → 归「产品设计」,标签 产品、用户
4. 出现 DAU、转化率、漏斗、月报、增长、数据分析 任一个 → 归「数据分析」,标签 数据、增长
5. 出现 React、组件、前端、CSS、渲染 任一个 → 归「前端工程」,标签 前端、技术
6. 出现 竞品、对比、A产品、B产品、市场、差异化 任一个 → 归「竞品研究」,标签 竞品、市场
7. 出现 技术债务、遗留代码、清理、重构 任一个 → 归「技术债务」,标签 技术债务、技术
8. 都没命中 → 归「其他」,标签留空
